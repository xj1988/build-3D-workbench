## 2. 主题结构

```json
"cream": {
  "label": "奶油蓝（默认）",
  "c":   { 3D 场景颜色，见下表 },
  "css": { "paper","paper2","accent","accent2","olive","ink","ink2" },
  "sky": { "morning": [天顶, 地平线, 地面, 太阳光晕], "afternoon": [...], "night": [...] }
}
```

`c` 里每个键管的东西：

| 键 | 用在 |
|---|---|
| `paper` `paperEdge` | 书页纸面、书页侧边 |
| `cover` | 书封皮、书塔里的一本书 |
| `grass` `grass2` | 岛和沙盘的草地顶面 / 草皮边缘、远处第三层山 |
| `rock` `rock2` `soil` `soil2` | 岛侧面和沙盘切面的地层、菜园土垄 |
| `water` `waterLight` | 河、池塘、瀑布、河岸 |
| `accent` `accent2` | 主强调色：灯塔条纹、邮筒、风车帆、帐篷、彩旗、花 |
| `butter` `lav` `mist` | 辅助色：黄（窗灯、太阳）、紫、雾蓝 |
| `sage` `sage2` `sage3` | 树冠、草、植物的三档绿 |
| `wood` `wood2` | 浅木 / 深木：桥、围栏、树干、梯子 |
| `stone` `stone2` | 石板、井、广场 |
| `roof` `roof2` | 屋顶主色 / 第二屋顶色（剪纸小镇） |
| `cream` | 墙面、车厢、便签 |
| `ink` | 路灯杆、细线、深色细节 |
| `metal` `skin` | 望远镜等金属件 / 小人皮肤 |

缺的键会自动用 cream 的值。

`css` 管界面：`paper`/`paper2` 卡片底色，`accent` 进度条和高亮，`accent2` 强调文字和选中，`olive` 完成状态，`ink`/`ink2` 正文/次要文字。

## 3. 自定义配色

用户给了品牌色、喜欢的颜色、或一张参考图的颜色时：

1. 写一个 `palette.json`，**只写要改的键**，其余自动回退：
```json
{
  "label": "品牌薄荷",
  "c": { "paper": "#F2F5EF", "accent": "#7CC6B0", "accent2": "#3E9A82", "roof": "#6FAE9C", "grass": "#CFE0C4", "water": "#A6D3D9" },
  "css": { "accent": "#7CC6B0", "accent2": "#2F7F6B", "ink": "#24332E" },
  "sky": { "morning": ["#BFE3DA", "#F4F7F2", "#E3EBE2", "#FFE9C8"], "afternoon": ["#E8C9A8", "#FBEFE2", "#EEDFCD", "#FFCB98"], "night": ["#0E1A1C", "#2C4A4C", "#1C2C2E", "#7FC0B0"] }
}
```
2. `python3 scripts/build_workbench.py --config my.json --palette palette.json --output out.html`，脚本会把它作为 `custom` 主题加入并启用（T 键仍可切到其他主题）。
3. 想永久加入模板：把它复制进模板 `THEMES_BEGIN/END` 里，起个英文名，同时在 `catalog.json` 的 `themes` 加一行说明。

## 4. 调色规则

这个风格好看的核心是“**低饱和、高明度、暖底色、一个主强调色**”。自定义时检查：

- **纸色 / 草地**：明度很高（HSL 的 L 85%～96%），饱和度低（S < 35%）。纸色略偏暖。
- **强调色** `accent`：L 65%～80%，S 40%～75%。`accent2` 是它更深一点的版本（L 再低 10%～15%）。
- **三档绿** `sage/sage2/sage3`：同一色相，明度差 8%～12%，不要用纯绿（#00FF00 这类）。
- **墨色** `ink`：不要纯黑，用很深的蓝灰/棕灰（L 15%～25%）。
- **天空** `sky.morning`：天顶比地平线深一点、偏冷；地平线接近纸色；第 4 个光晕色偏暖黄。夜晚天顶要非常深（L < 15%），这样灯光才出效果。
- 一个主题里饱和度最高的颜色不超过 2 个；如果用户的品牌色很艳，把它放在 `accent2`，`accent` 用它的浅色版。
- 改完后在白天和夜晚各看一次：白天不能刺眼，夜晚灯和窗要能亮出来。
