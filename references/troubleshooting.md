# 排障手册

顺序永远是：**找到第一条错误 → 做最小修复 → 重新生成并复查**。不要因为白屏就重写整个文件。

| 现象 | 先查 | 怎么修 |
|---|---|---|
| 生成失败：不是合法 JSON | 报错里的行号列号 | 多余逗号、中文引号“”、单引号、注释都不行 |
| 生成失败：kit 只能是… | 拼写 | 用 `--list` 看准确名字，区分大小写（`noteTree`、`postOffice`） |
| 一直显示“正在搭建小世界…” | 浏览器控制台第一条红字 | 多数是 CDN 没加载：检查网络、importmap 是否还在 module 脚本前面、版本是否都是 0.169.0 |
| 加载层显示“出错了：…” | 那句错误 | 改过模板代码时，回到备份版本，只重做最后一处改动 |
| 双击打开是白屏 | 是不是 `file://` | 用 `python3 -m http.server` 打开；部分浏览器禁止本地文件加载模块 |
| 建筑互相穿插 | 是否手写了 `pos` | 删掉 `pos` 让引擎自动摆；或拉开到两者 r 之和以上 |
| 建筑压在河上 | 自定义了 `river.points` 或 `pos` | 让区域离河道中心 ≥ r + 0.6 |
| 建筑压在书脊上 | 立体书 `|x| < 1.3` | 把 x 移到 ±1.3 以外 |
| 漂浮岛角上的建筑悬空 | 放在角落 | 角落（|x|>8.6 且 |z|>4.8）只放 r ≤ 1.2 的积木，或往里挪 |
| 全景没框住 / 太小 | 改过底座尺寸 | 调该底座的 `view.hw / hh` |
| 浮标互相盖住 | 两个区域前后紧挨 | 拉开 z 方向距离，或把矮的放前面 |
| 画面太暗 | 是否在夜晚模式 | 点太阳按钮；自定义主题的天空颜色是否太深 |
| 画面发白 / 刺眼 | 自定义主题饱和度太高或纸色太白 | 按 themes.md 第 4 节调；不要加大曝光 |
| 太糊 | 移轴 | `§10` 把 `uAmt` 从 3.0 降到 2.0，或 `uRange` 加大到 0.22 |
| 卡顿、发热 | 设备性能 | `"quality": "low"`；`decor.flowers` 降到 0.5；区域少于 7 个 |
| 换主题后某个东西没变色 | 积木里写死了色值 | 改成主题键，见 kits.md 第 3 节 |
| 文字是方块 / 不是手写体 | 字体没加载 | 正常回退，不影响使用；需要手写体就确保能访问 Google Fonts |
| 修改了配置但页面没变 | 浏览器里存了旧修改 | 编辑窗点“恢复初始内容”；或换新的 `storageKey`（脚本默认会按内容生成新名字） |
| 刷新后编辑丢失 | 浏览器禁止本地存储（隐私模式、某些内嵌预览） | 如实告诉用户；把编辑窗里的 JSON 复制出来做成配置重新生成 |
| 漫步走不过去 | 河上只能走桥 | 在 `river.bridges` 加桥位置；建筑周围也不能穿 |
| 点击地面小人不走 | 目标被挡 | 正常：只走直线，不会自动绕路，用 WASD |
| 截图按钮没反应 | 在某些受限沙箱预览里 | 沙箱禁止下载；用浏览器直接打开 HTML 再截图 |
| 巡游中断后不能拖动 | — | 按 Esc 或点“回到全景” |
| 翻页没反应 | 是否在漫步/巡游中、已到首/末页、页面正在翻 | 翻页与漫步/巡游/上一次翻页互斥；首末页用页角按钮的另一侧 |
| 翻页后浮标不对 / 内容还是上一页 | 翻页动画未结束就操作 | 等纸页落定（约 2.5 秒）；仍不对就是改坏了 §8.5，回退模板 |
| 配了 pages 顶层 zones 被忽略 | 有 pages（≥2 页）时页级字段以 pages 为准 | 把内容搬进 pages[].zones，或删掉 pages 退回单页 |
| 旧存档显示新页数不对 | 浏览器存的是旧结构 | 编辑窗“恢复初始内容”；或 storageKey 换名（脚本按内容自动生成，改配置即换） |

CDN 不可访问时：说明页面依赖公开 CDN。只有用户同意且环境允许时，才把 Three.js 0.169.0 的相关文件下载到本地并改 importmap 指向本地路径；不要用来路不明的镜像，不要声称单个 HTML 能离线运行。
