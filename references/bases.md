# 底座手册

底座是整个场景的“地”。模板 `§6 BASES` 里有 3 个，它们共享同一块约 20 × 13 的平面坐标，所以同一份 zones 配置换底座也能用。

## 目录
1. 三种底座
2. 底座接口
3. 新增底座

## 1. 三种底座

### book 立体书
- 外观：布面封皮带白色缝线，左右两页纸，中间书脊向下凹，纸边有页层线，左页有一条书签带。纸面画点阵、年月和三句手写字（`pageNotes`）。
- 多页：配置顶层 `pages`（2～4 页）后可翻页——←/→ 或页角按钮，纸页绕书脊扫过；每页自己的 zones/pageNotes/modes，**场景也按页独有**（落位旋转、装饰散布按页独立，背景布景两套：`default` 远山+小镇+彩虹、`deep` 海沟剪影+发光海草，`pages[].backdrop` 选择）；河、桥、纸船/河畔行人是全书的。结构见 config-schema.md 第 7 节。
- 背景：左页后排是两层剪纸远山 + 四棵纸片树 + 立在杆子上的纸太阳（夜里变月亮）；右页后排是剪纸小镇（窗户夜里亮）和四色纸彩虹。
- 注意：书脊附近 `|x| < 1.3` 不放建筑；整个场景高度较低，镜头最平稳。
- 最适合：手账、创作、读书、旅行、日记。

### island 漂浮岛
- 外观：圆角矩形岛屿（超椭圆 + 轻微波浪边），顶面草地带细噪点，侧面一圈圈往下收的土层、岩层（低多边形），垂下藤蔓；前缘有小池塘和一道小瀑布；岛下漂着云朵，四周有 4 个会上下浮动的小浮岛。
- 背景：后排剪纸远山 + 纸片树 + 纸太阳/月亮（范围比书窄，避免露出岛边）。
- 注意：四个角被削圆，大建筑不要放在最角落；岛的立体感需要镜头稍微斜看，默认全景已经调好。
- 最适合：个人成长、梦想、品牌世界观、店铺、游戏感。

### diorama 方块沙盘
- 外观：放在两层木质展示台上的方形沙盘，四周露出草皮、土壤、碎石、岩层四层切面（每层略缩进），切面上嵌着小石子；展示台正面有一块写着 `title` 的金色铭牌。
- 背景：整排剪纸远山 + 纸片树 + 纸太阳/月亮。
- 注意：边界是直的，可以放满四个角；地面最平，适合放很多区域。
- 最适合：学习、项目、团队看板、作品集、展示。

## 2. 底座接口

每个底座是一个对象，必须提供：

| 成员 | 作用 |
|---|---|
| `ground(x,z)` | 返回地面高度。建筑、河、花草、小人都靠它贴地 |
| `inside(x,z,pad)` | 能否在这里摆东西（离边缘至少 pad） |
| `walkIn(x,z)` | 漫步小人能否走到这里 |
| `build()` | 建模：往 `world` 里加网格；把可点击行走的地面网格放进 `groundMeshes`；用 `themeHooks.push()` 注册换主题时要重画的纹理；最后 `addShadowPlane(y)` |
| `top` | 地面大致高度（背景剪纸层、纸飞机用） |
| `back` | `{z, x0, x1, pole}` 背景剪纸层的 z 位置、左右范围、太阳杆的 x |
| `view` | `{hw, hh, ty}` 全景镜头要框住的半宽、半高、目标点高度 |

## 3. 新增底座

例如用户要“甜甜圈”“云朵”“荷叶”“桌面”。

1. 复制 `BASES.diorama`（最简单）为 `BASES.xxx`。
2. 写 `ground`：保持起伏很小（±0.1 以内），否则建筑会悬空。中心区域必须足够平。
3. 写 `inside` 和 `walkIn`：覆盖 9 个默认空位（见 config-schema.md 第 5 节）和默认河道；如果形状装不下，就在文档里说明“这个底座必须给每个区域写 pos”。
4. 写 `build`：
   - 顶面：`PlaneGeometry` 或自己生成网格，逐顶点 `setY(ground(x,z))`，然后 `computeVertexNormals()`；材质用 `canvasTex` 画的纹理（底色 `hex('grass')` 或 `hex('paper')` + 细噪点）。
   - 侧面/厚度：一定要有“厚度”和分层，这是微缩模型感的来源。
   - 把顶面网格 push 进 `groundMeshes`。
5. 把名字加到：`normalize()` 里的底座白名单、`assets/catalog.json` 的 `bases`、`scripts/build_workbench.py` 自动读取 catalog（无需改）。
6. 生成测试页，依次检查：全景是否完整（调 `view`）、9 个空位是否都在地上、河是否贴地、背景剪纸层是否露在外面（调 `back`）。
