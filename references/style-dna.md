# 风格基因

这一页解释“为什么这个工作台看起来像手作微缩模型”。**改代码之前读一遍**，任何改动都不能破坏下面这些点。只改配置的话可以跳过。

## 一句话

> 奶油色纸艺 + 圆润低多边形 + 柔和日光 + 移轴微缩 + 手写字 UI。像一个放在桌上的手工模型，被午后阳光照着。

## 1. 形状

- **一切都是圆的**：方块用 RoundedBox（圆角 0.03～0.15），树冠是几个球叠在一起，石头是压扁的球，屋顶用低段数圆锥 + flatShading 做出纸折感。
- **比例偏 Q**：建筑矮胖，门窗偏大；小人约 0.45 高，头身比约 1:2。
- **有厚度**：书页有页层线，岛有地层，沙盘有切面，剪纸层有 0.05 的厚度。薄片和无厚度平面会显得“假”。
- **细节分三级**：主体（建筑）→ 中景（树、路灯、桥、串灯）→ 微观（花、草、石板、纸船、小人）。微观层数量多、尺寸极小，用 InstancedMesh。

## 2. 颜色

- 低饱和、高明度的粉彩色，暖白底；一个主强调色 + 2～3 个辅助色。
- 同一类物体用同色相不同明度（三档绿、两档木、两档石），避免一块块纯色。
- 深色只用于细线和小面积（路灯杆、窗框、小人头发），不用大面积黑。
- 所有颜色来自主题键，换主题时整体一起变。

## 3. 材质

| 用途 | 材质 | 参数 |
|---|---|---|
| 大多数物体 | MeshStandardMaterial | roughness 0.78～0.95，metalness 0 |
| 树冠、头发、云 | MeshPhysicalMaterial | sheen 0.8，sheenRoughness 0.55（绒感边缘光） |
| 屋顶、岩层 | flatShading | 低多边形折面 |
| 水面 | Standard + 流动 CanvasTexture | roughness 0.25，微弱自发光 |
| 金属件 | metalness 0.55，roughness 0.35 | 只用在望远镜、轴心等小件 |
| 玻璃 | 透明 0.28，roughness 0.08，不写深度 | 温室 |

不要用镜面反射、环境贴图、法线贴图、PBR 贴图包，它们会破坏“纸感”。

## 4. 光

灯光组合固定，按顺序：
1. 半球光（天空色/地面色，强度 1.3）——整体柔和底光。
2. 主方向光（暖白，2.4，左上方）+ 阴影（2048，PCFSoft，radius 6，bias -0.0004）。
3. 冷色补光（0.55，右后方）——让暗面偏蓝，不发黑。
4. 暖色轮廓光（0.5，正后方）——勾出边缘。
5. 夜晚：主光降到 0.55 冷蓝；所有 `glow` 材质提亮到 2～3.5；路灯点光源亮起；泛光加强到 0.95。

色调映射用 NeutralToneMapping，曝光 1.0。

## 5. 后期（微缩感的关键）

顺序：RenderPass → UnrealBloom（0.35, 半径 0.55, 阈值 0.86）→ 水平移轴模糊 → 垂直移轴模糊 + 暗角 0.22 → OutputPass。

移轴模糊按屏幕纵向位置做：画面中间一条清晰带（uRange 0.17），上下渐渐模糊（uAmt 3.0）。这让场景看起来像近距离拍的小模型。太糊就减 uAmt，不要关掉。

## 6. 氛围

- 天空是反面大球 + 三色渐变 Shader + 太阳方向光晕；雾的远近随相机距离变化。
- 空中漂浮暖色光点（加法混合）、远处大光斑、纸飞机带光点尾迹、河里漂纸船、河边有人散步。
- 所有动画慢而小：摆动 ≤ 0.3 弧度，周期 2～6 秒。快速、大幅度的动画会破坏宁静感。

## 7. 镜头

- PerspectiveCamera 30°（偏长焦，透视弱，像俯拍模型）。
- 全景方向 (0, 0.66, 0.75)，自动按画面比例算距离框住整个底座。
- 点击区域时 1.5 秒缓动飞到斜上方特写；拖动可中断飞行。
- 限制最大俯仰角 1.32，不能钻到地面以下。

## 8. 界面

- 字体：标题和数字用手写体 Long Cang，正文 Noto Sans SC，都有系统字体回退。
- 卡片：纸色底、圆角 6～18、柔和投影；计数卡带歪歪的半透明纸胶带，轻微旋转 ±2°。
- 工具条和底部轨道用半透明 + backdrop blur。
- 3D 浮标：圆角胶囊 + 底部小三角，每帧投影跟随建筑；当前时段相关的区域高亮。
- 界面颜色全部用 CSS 变量，跟主题联动。
