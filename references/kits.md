# 积木手册（建筑库）

模板 `§7 KITS` 里有 19 个积木。每个积木是一个函数，在**本地坐标**里建模：地面是 y=0，中心在原点，正面朝 +Z（朝镜头）。引擎负责把它放到底座上、处理点击、标签、碰撞和镜头。

2. 选积木的技巧

## 2. 选积木的技巧

- **意义优先**：先按“适合表达”选，再看外观。用户说“读书”就是书塔，不要因为好看换成摩天轮。
- **高矮交错**：高的（灯塔、书塔、摩天轮、风车、瞭望台、便签树）和矮的（广场、营地、喷泉、菜园、温室）交替摆，避免一排都高或都矮。
- **大件放后排或两侧**：菜园、摩天轮、小屋占地大，适合空位 1、6、7（左后、右后、右前）；广场适合正中空位 5。
- **同一积木最多 2 个**，3 个以上画面会很单调。真的需要更多同类，就换成另一个意思接近的积木。
- **不超过 7 个时效果最好**；8～9 个时把 `decor.trees` 调到 0.6 左右，让画面透气。

## 3. 新增积木

只有当 19 个积木都表达不了用户的需求时才新增（例如用户要“健身房”“宠物屋”“音乐台”）。

### 步骤

1. 在模板 `§7` 末尾、`§8` 之前，复制下面的骨架。
2. 名字加到 `KIT_NAMES` 数组（`§3` 附近）和 `assets/catalog.json` 的 `kits`（填 r、h、label、means、data）。
3. 生成一份只有这个积木的测试配置，逐步在浏览器里看。

```js
/* 17 音乐台：圆形舞台 + 顶棚 + 跳动的音符 */
KITS.bandstand=(g,z)=>{
  // ① 地基：低矮、圆角，颜色用石材键
  add(g,cyl(1.1,1.15,0.18,24),std('stone'),0,0.09,0);
  // ② 主体：用 rbox / cyl / ball，颜色只用主题键（cream/accent/roof/wood…）
  for(let i=0;i<6;i++){const a=i/6*Math.PI*2;add(g,cyl(0.05,0.05,1.3,8),std('cream'),Math.cos(a)*0.9,0.83,Math.sin(a)*0.9)}
  add(g,new THREE.ConeGeometry(1.25,0.6,6),flat('roof'),0,1.78,0);
  ball(g,0.08,std('accent2'),0,2.12,0);
  // ③ 一个会动的小细节（必须用 dt 或 t，不要按帧累加固定值）
  const note=add(g,rbox(0.12,0.2,0.04,0.03),glow('butter','butter',0.3,2.2),0,1.0,0);
  updaters.push((dt,t)=>{note.position.y=1.0+Math.sin(t*2)*0.15;note.rotation.y=t});
  // ④ 一个人物或盆栽，增加尺度感
  person(g,0.4,0.2,'lav','ink',0.5);
  // ⑤ 数据联动（可选）：用 z.value(0~1) 或 z.cfg.panel.items
  z.update=()=>{note.scale.setScalar(0.6+z.value)};
  return{h:2.4,r:1.25,dist:7.5};   // h 浮标高度，r 占地半径，dist 特写距离
};
```

### 必须遵守

- **尺寸**：占地直径 2～3.5，总高 1.8～4.2。比这大会挤，比这小看不清。一个小人约 0.45 高，用它校准比例。
- **只用模板的帮手函数**：`add / rbox / cyl / ball / std / soft / flat / glow / metal / person / pot / flagOn / bunting / canvasTex / redraw`。不要 `new MeshBasicMaterial` 写死颜色（发光点除外）。
- **颜色只用主题键**：`paper cream ink accent accent2 butter lav mist sage sage2 sage3 roof roof2 wood wood2 stone stone2 soil soil2 grass grass2 rock rock2 water waterLight metal skin`。这样换主题时会自动变色。
- **形状要“软”**：方块一律 `rbox`（圆角），树冠、头、石头用 `ball`，屋顶可以用 `flat()` 做低多边形。避免细长尖锐的东西。
- **几何体复用**：同一形状重复超过 20 次时用 `InstancedMesh`（参考喷泉水滴、广场地砖）。
- **动画**：`updaters.push((dt,t)=>{…})`，速度乘 `dt` 或用 `t` 的正余弦；幅度要小（旋转 ≤ 0.3 弧度摆动，位移 ≤ 0.2）。
- **夜景**：窗户、灯泡用 `glow(颜色键, 发光键, 白天强度, 夜晚强度)`，夜晚强度 2～3.5。
- **画布文字**：用 `canvasTex(w,h,(ctx,w,h)=>{…})` 画，颜色用 `hex('键')`，并在 `z.update` 里 `redraw(tex)`。
- **不要**：加点光源超过 1 个、加阴影贴图、加后期、改相机、改其他积木。

## 4. 可复用的小部件

| 函数 | 作用 |
|---|---|
| `person(parent,x,z,上衣键,头发键,朝向)` | 0.45 高的小人 |
| `pot(parent,x,z,盆色键,花色键)` | 一盆圆球花 |
| `flagOn(parent,x,y,z,颜色键,杆高)` | 会飘的小旗 |
| `bunting(parent,起点Vector3,终点Vector3,数量,下垂)` | 三角彩旗串 |
| `treeAt(parent,x,y,缩放,种类0~3)` | 一棵绒感小树（种类决定颜色组合） |
| `bulbMesh(parent,点数组,大小)` | 一串会闪的灯泡（夜里变亮） |
| `windowGlow()` | 夜里发光的窗户材质 |
| `waterMat()` | 会流动的水面材质 |
