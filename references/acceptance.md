# 验收清单

每项记“通过 / 失败 / 未验证”。没做的不能写成通过。静态检查和浏览器检查分开报告。

## 静态（必须）
- [ ] `build_workbench.py` 实际运行成功，没有未处理的“提醒”
- [ ] `validate_workbench.py` 输出 PASS（无 Node 时注明跳过语法检查）
- [ ] 没有覆盖用户没让覆盖的文件
- [ ] 标题、区域名、面板内容都是用户给的，或明确标为示例
- [ ] HTML 里没有本机路径、账号、密钥、私人链接、照片

## 浏览器（有浏览器工具时必须）
- [ ] 加载层消失，`browser_check.js` 返回 `ok: true`
- [ ] 全景：底座完整、建筑不穿插不悬空、浮标不重叠
- [ ] 点每个区域（或按 1～9）：镜头飞过去，面板内容正确，× 能关闭
- [ ] 晨间 / 午后 / 深夜切换平滑；夜里窗户、路灯、串灯亮起，地面仍可辨认
- [ ] T 换主题：3D 和界面颜色一起变，刷新后保持
- [ ] P 漫步：WASD 能走、Shift 跑、能过桥、不穿建筑、靠近出现“按 E 进入”，Esc 退出回全景
- [ ] D 巡游：依次飞过所有区域，中途点击可中断
- [ ] 铅笔编辑：改标题立即生效；勾选清单后刷新仍保留
- [ ] H 隐藏界面、F 取景框可开关
- [ ] 窄窗口（约 400 宽）界面不互相遮挡，面板能关闭

## 翻页（配了 pages 的立体书才需要）
- [ ] `browser_check.js` 在**每一页**空闲时都返回 `ok: true`（info.page 显示对应页码）
- [ ] ←/→ 方向键和右下角页角按钮都能翻页；首/末页对应按钮呈禁用态
- [ ] 翻页动画：旧区收起、纸页扫过、新区弹起，全程无穿模、无残影；纸面手写字和页码随页变化
- [ ] 翻到新页后：浮标数 = 该页区域数，点区域开面板内容正确，页角章显示「N / 总数 · 页名」
- [ ] 翻页中按 P / D / 数字键 / 再按方向键都被安全忽略；翻页结束后一切恢复
- [ ] 刷新后停留在上次翻到的页；页内勾选清单保存后换页再翻回来仍保留

## 交付说明（必须写给用户）
- 文件在哪、怎么打开、需要联网
- 主要操作方式（拖动、滚轮、点击、P/D/T/S/F/H、铅笔编辑；多页立体书加 ←/→ 翻页）
- 修改只存在当前浏览器
- 哪些是示例内容，哪些检查没做
- 不要声称：有后端、自动同步数据、AI 分析、自动寻路、离线可用、固定帧率
