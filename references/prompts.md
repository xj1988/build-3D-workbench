# 提示词模板

给用户复制使用，也给 agent 参考“需求长什么样”。方括号里的内容按需替换，不需要的行直接删掉。

## 1. 最短版（什么都不想填）

```
用 build-3d-workbench skill，做一个 3D 工作台。用默认预设生成，校验通过后把 HTML 给我，告诉我怎么打开。
```

## 2. 标准版（推荐）

```
用 build-3d-workbench skill 帮我生成一个 3D 工作台。

【用途】[例：记录我的自律计划 / 小店经营 / 内容创作]
【底座】[立体书 / 漂浮岛 / 方块沙盘，不确定就让你选]
【配色】[奶油蓝 / 樱花粉 / 抹茶绿 / 海盐蓝 / 橘子汽水 / 薰衣草 / 燕麦极简，或给色值]
【标题】[≤12 字]　【副标题】[一句话]　【漫步昵称】[≤6 字]
【区域】（3～9 个，每行：名字 —— 代表什么 —— 面板里放什么）
- [灵感井 —— 收集想法 —— 列出：A、B、C]
- [目标灯塔 —— 年度目标 —— 进度 45%]
- [……]
【右上角数字】[坚持天数 42、本月完成 18]
【底部进度条】[收集 → 筛选 → 制作 → 发布 → 复盘，当前第 3 步]（不要就写“不要”）
【三个时段文案】[晨间：…… / 午后：…… / 深夜：……]（可省略）

要求：
1. 先把需求整理成配置 JSON（从最接近的预设复制再改），区域位置让引擎自动摆。
2. 用脚本生成并校验；有浏览器就实测并截图，没有就说明未实测。
3. 不要从零写 Three.js，不要读取我没提供的个人资料。
4. 交付 HTML，并告诉我怎么打开、怎么操作、哪些内容是示例。
```

## 3. 扩展版（要新造型时追加）

```
另外我需要一个现有积木里没有的建筑：[例：健身房 —— 小房子 + 门口哑铃 + 跳动的心形]。
请按 skill 的 kits.md「新增积木」规则加一个积木，只用主题色键、圆角造型、轻微动画，
尺寸和现有积木一致；加完先单独测试再放进我的工作台。
```

## 4. 自定义配色

```
配色用我的品牌色：主色 [#7CC6B0]、深色 [#2F7F6B]、背景偏 [暖白]。
请按 themes.md 的调色规则做一个 palette.json（保持低饱和高明度），用 --palette 生成，白天和夜景各检查一次。
```

## 5. 修改已有工作台

```
这是我之前生成的工作台配置 [附 config.json 或粘贴 JSON]。
请只改：[例：把配色换成樱花粉；把「目标灯塔」挪到右前方；加一个「阅读书塔」]。
其他保持不变，重新生成并校验。
```

## 写提示词的要点

- **说意思，不说造型**：写“这里代表我的阅读计划”，agent 会选书塔；不需要描述书塔长什么样。
- **数字给准**：进度写百分比或“完成 3/8”，计数写具体数字。
- **不确定的留空**：底座、配色、位置都可以不写，skill 有默认值，比随口指定效果更好。
- **一次改一件事**：修改时只说要改的部分，避免 agent 重做整个场景。
