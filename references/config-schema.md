# 配置手册（SCENE JSON）

配置就是模板里 `/* SCENE_BEGIN */ … /* SCENE_END */` 之间的那段 JSON，也是 `--config` 读取的文件。必须是**合法 JSON**：双引号、不能有注释、最后一项后面不能有逗号。

## 目录
1. 完整示例
2. 顶层字段
3. zones（区域）
4. panel（详情面板）
5. 坐标
6. 运行时编辑与存储

## 1. 完整示例

```json
{
  "title": "我的梦想岛",
  "subtitle": "把每天的小事，种成一座会发光的岛",
  "nickname": "漫游者",
  "storageKey": "dream-v1",
  "base": "island",
  "theme": "cream",
  "quality": "standard",
  "frameRatio": "3:4",
  "river": { "enabled": true, "bridges": [0.3, 0.72] },
  "decor": { "trees": 1, "flowers": 1, "walkers": 10, "planes": 3, "boats": 6, "garlands": true, "sparkles": true },
  "modes": {
    "morning":   { "name": "晨间 · 灵感", "sub": "清晨的岛很安静", "focus": [0, 1] },
    "afternoon": { "name": "午后 · 制作", "sub": "去小屋把想法做出来", "focus": [2, 3] },
    "night":     { "name": "深夜 · 复盘", "sub": "灯塔亮了", "focus": [4, 5] }
  },
  "stats": [ { "k": "坚持天数", "v": 42 }, { "k": "本月完成", "v": 18 } ],
  "track": { "label": "本周计划", "steps": ["收集", "筛选", "制作", "发布", "复盘"], "current": 3 },
  "zones": [
    { "id": "well", "kit": "well", "name": "灵感井", "info": "收集零散想法",
      "panel": { "lead": "每个念头先丢进井里。", "items": [ { "t": "桌面物品的一天", "s": "周一" } ] } },
    { "id": "light", "kit": "lighthouse", "name": "目标灯塔", "info": "年度目标", "value": 0.45,
      "panel": { "progress": { "label": "年度目标", "value": 0.45 } } }
  ]
}
```

## 2. 顶层字段

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `title` | 文字 ≤ 12 字 | — | 左上角手写大标题，也是网页标题；沙盘底座的铭牌也写它 |
| `subtitle` | 文字 ≤ 30 字 | 空 | 标题下一行；如果当前时段 `modes.x.sub` 有值，优先显示时段文案 |
| `nickname` | 文字 ≤ 6 字 | 漫游者 | 漫步模式头顶的名字 |
| `storageKey` | 字母数字横线 | 自动 | 浏览器本地存储名。生成脚本会按配置内容自动生成，不同工作台不会串数据 |
| `base` | `book` / `island` / `diorama` | `island` | 底座，见 bases.md |
| `theme` | 主题名 | `cream` | 见 themes.md |
| `quality` | `standard` / `low` | `standard` | low：关闭泛光和移轴、阴影 1024、花草减半、不加路灯点光源 |
| `frameRatio` | `3:4` `4:3` `16:9` `9:16` `1:1` | `3:4` | 按 F 出现的取景框起始比例（只是参考线，不改变画布） |
| `pageNotes` | 文字数组 ×3 | 内置 | 仅立体书：纸面上的三句手写字 |
| `river.enabled` | 布尔 | true | 是否有河（连带纸船、河边小人、石板路） |
| `river.points` | `[[x,z],…]` ≥3 个 | 内置 | 自定义河道控制点；改了以后要自己给所有区域写 `pos` 避开河道 |
| `river.bridges` | 0.05～0.95 的数组 | `[0.3,0.72]` | 桥在河上的位置比例；漫步小人只能从桥上过河 |
| `decor.trees` / `decor.flowers` | 0～2 | 1 | 树/花草密度倍数，0 就是不要 |
| `decor.walkers` / `planes` / `boats` | 0～16 整数 | 10 / 3 / 6 | 河边散步小人、纸飞机、纸船数量 |
| `decor.garlands` | 布尔 | true | 路灯到建筑之间的串灯 |
| `decor.sparkles` | 布尔 | true | 空中漂浮光点和远处光斑 |
| `modes.morning/afternoon/night` | 对象 | — | `name` 工具栏提示文字；`sub` 该时段副标题；`focus` 该时段高亮的区域序号（从 0 开始） |
| `stats` | `[{k, v}]` ≤ 4 | `[]` | 右上角纸胶带计数卡。`v` 是数字会有滚动动画，也可以是文字如 `"11.5h"` |
| `track` | 对象 | 无 | 底部进度条：`label` 标题、`steps` 2～7 个步骤、`current` 当前第几步（从 1 开始）。点节点可改进度。删掉整个字段就不显示 |
| `zones` | 数组 1～9 个 | — | 见下节 |

## 3. zones（区域）

| 字段 | 必填 | 说明 |
|---|---|---|
| `kit` | ✔ | 积木名，16 选 1，见 kits.md |
| `name` | ✔ | ≤ 6 字，浮标和面板标题 |
| `id` | | 唯一英文名，便于以后改配置时对应 |
| `info` | | ≤ 10 字，浮标第二行（悬停或高亮时显示） |
| `pos` | | `[x, z]`，不写就自动摆放 |
| `scale` | | 0.5～1.6，默认 1 |
| `rot` | | 绕竖直轴旋转的角度（度），正数逆时针 |
| `value` | | 0～1，驱动灯塔亮窗、广场亮灯、风车转速 |
| `sign` | | 邮局招牌、咖啡车黑板标题（≤ 5 字） |
| `panel` | | 点击后右侧详情面板，见下节 |

`value` 不写时按顺序取：`panel.progress.value` → 清单完成比例 → 0.6。

## 4. panel（详情面板）

所有字段都可选，按下面顺序从上到下显示。文字全部会被转义，可以放任何字符。

| 字段 | 结构 | 显示为 |
|---|---|---|
| `lead` | 文字 | 标题下的一段说明 |
| `chips` | `[{k, v}]` ≤ 4 | 一排数字小卡 |
| `progress` | `{label, value}` | 进度条（value 0～1） |
| `itemsTitle` | 文字 | 列表小标题 |
| `items` | `[{t, s}]` | 列表：左边 `t`，右边灰色 `s` |
| `checklistTitle` | 文字 | 清单小标题（默认“清单”） |
| `checklist` | `[{t, done}]` | 可勾选清单，勾选会保存并更新建筑 |
| `text` | 文字（可换行 `\n`） | 浅色文本框，适合放文稿、备注 |
| `tags` | 文字数组 | 一排标签 |

## 5. 坐标

- 所有底座共用同一套平面坐标：**X 左右（-9.4～9.4），Z 前后（-5.4～6.0），Z 越大越靠近镜头**。单位约等于一个建筑的半宽。
- 9 个自动空位（按顺序使用）：
  `[-8.2,-4.6]` 左后、`[-4.2,-2.4]` 左中后、`[-8.4,1.4]` 左中、`[-2.8,4.8]` 左前、`[3.0,0.4]` 正中偏右、`[7.3,-4.5]` 右后、`[7.0,3.8]` 右前、`[2.6,4.6]` 中前、`[-1.2,-4.0]` 中后。
  它们已避开默认河道。写了 `pos` 的区域会占掉附近（2.2 以内）的空位。
- 两个区域中心距离要 ≥ 两者占地半径之和（kits.md 里的 r）。脚本会提醒。
- 立体书中间是书脊折缝，`|x| < 1.3` 的位置不要放建筑。
- 漂浮岛是圆角矩形，四个角会被削掉，`|x| > 8.6 且 |z| > 4.8` 的角落放不下大建筑。
- 背景剪纸山在最后一排（z ≈ -5.4 以后），不要把高建筑放到 z < -5。

## 6. 运行时编辑与存储

- 页面左侧铅笔按钮打开编辑窗：标题、副标题、昵称、配色，以及整份配置的 JSON。
- 只改文字/数字/面板 → 立即生效；改了底座、积木种类、位置、数量、河、装饰 → 保存后自动刷新重建。
- 修改保存在浏览器 localStorage（键名 `wb:` + storageKey），“恢复初始内容”会清掉它。不会写回 HTML 文件。
- 想把浏览器里的修改固化：打开编辑窗，复制 JSON 文本框内容，补上 `title/subtitle/nickname/theme` 后作为 `--config` 重新生成。
